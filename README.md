# คลังข้อสอบเภสัชกรรมไทย (Thai Pharmacy Quiz)

เว็บแอปทำข้อสอบปรนัย **เภสัชกรรมไทย / เวชศาสตร์แพทย์แผนไทย** แบบไฟล์เดียวจบ
เปิด `index.html` แล้วใช้งานได้ทันที — ไม่ต้องติดตั้งอะไร ไม่ต้องต่อเน็ต

## ใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (หรือเปิดผ่าน GitHub Pages ด้านล่าง)

- **เลือกชุดข้อสอบ** จาก dropdown: ทุกชุด / ชุดที่ 1–5
- **สุ่มข้อสอบ** ไม่เรียงข้อทุกครั้งที่กด "ข้อถัดไป"
- **ตัวเลือกเรียง ก ข ค ง จ** ตามลำดับ
- **กดตอบแล้วเฉลยทันที** — ถูกขึ้นสีเขียว ผิดขึ้นสีแดงพร้อมไฮไลต์ตัวเลือกที่ถูก
- **นับคะแนน** ทำแล้ว / ถูก / ผิด / ความแม่นยำ

## ข้อมูล

| ชุด | จำนวนข้อ |
|---|---|
| ชุดที่ 1 | 950 |
| ชุดที่ 2 | 904 |
| ชุดที่ 3 | 434 |
| ชุดที่ 4 | 366 |
| ชุดที่ 5 | 512 |
| **รวม** | **3,166** |

ข้อมูลฝังอยู่ใน `index.html` โดยตรง (inline JSON) จึงเปิดจาก `file://` ได้เลย
ส่วน `all_questions.json` เป็นสำเนาข้อมูลสำหรับนำไปใช้ต่อ

โครงสร้างแต่ละข้อ:

```json
{
  "id": 11,
  "question": "ฤาษีตนใดบริโภคผลดีปลี",
  "options": ["ก. ...", "ข. ...", "ค. ...", "ง. ..."],
  "answer": ["ก"],
  "source": 1
}
```

## ที่มาของข้อมูล

แปลงจากไฟล์ข้อสอบตัวอย่างชุดที่ 1–5 ซึ่งเป็นไฟล์สแกน
ข้อความผ่านการตรวจแก้คำผิดจาก OCR แล้ว (รูปเขียน "น้ำ" เพี้ยน, วรรณยุกต์หาย,
ตัวเลือกสลับลำดับ, เลขไทย → เลขอารบิก)

> ข้อจำกัด: ต้นฉบับเป็นไฟล์สแกน ยังมีจุดที่ OCR อ่านเพี้ยนหลงเหลืออยู่บ้าง
> โดยเฉพาะวรรณยุกต์สลับ ( ่ / ้ ) และพยัญชนะพ้องรูป

## การใช้งานเชิงเทคนิค

ไฟล์ทั้งหมดเป็น static — ไม่มี dependency ไม่มี build step

```bash
# เปิดดูในเครื่อง
open index.html

# เสิร์ฟผ่าน HTTP (ถ้าต้องการ)
python3 -m http.server 8000
```
